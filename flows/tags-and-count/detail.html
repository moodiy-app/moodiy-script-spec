What it does

A small flow that runs after you save an entry:

  1. Tags lists the tags. If this step fails, the flow stops. Its output goes to the next step.
  2. Word Count counts the words and adds what the first step said to its message.

Each step has an argument that you can set in Moodiy: limit for Tags (how many tags to keep, 5 by default) and show_files for Word Count (list the attachments, on by default). Your values are kept when the flow is updated.

Installing the flow also installs the two scripts, if you do not have them yet. Both are JavaScript scripts that run inside Moodiy.
