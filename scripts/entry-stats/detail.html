What it does

Counts the words and the characters of the entry body, and hands the summary (for example 42 words, 230 characters) to the next step.

Files

  • entry-stats.sh: the script.
  • lib/json.sh: small helpers that the script loads from its own folder.

Runs outside Moodiy's sandbox. It is a Unix script, so it can do anything your account can do. This one only reads the request and prints a result. Read the files before you install it.
